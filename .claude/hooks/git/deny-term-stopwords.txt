# Ordinary words that install-git-hooks.ps1 -TermsFrom never writes into the deny list.
# A folder name split at capitals can yield a fragment that is also a common word (a student
# folder "SmithGrant" gives "grant"); written as a term it would refuse ordinary prose in
# every repository on the machine (Issue #70, M1). Data, not code (R6): one lowercase word
# per line, ASCII, no accents (the installer compares the folded spelling too). A name that
# really is one of these words goes in private-terms.extra.txt, which this list never filters.
