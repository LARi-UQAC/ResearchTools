Look at the chart in the image. Read what is printed on it and count what is drawn.

Return one JSON object with these keys and nothing else:

- x_title: the title written on the horizontal axis, copied exactly, including any unit written in it.
- y_title: the title written on the vertical axis, copied exactly, including any unit written in it.
- unit: the unit alone, as written with the vertical axis title (a title Mass (kg) has the unit kg).
- curve_count: the number of separate curves drawn, as an integer.
