# wp-portfolio-sync dependencies.

#   (never yaml.load), since mapping.yaml is researcher-supplied input.
# requests: the WordPress REST API client. Imported lazily, only inside
#   make_session(), so the offline test suite never needs it installed and

#   stdlib xml.etree.ElementTree only if it is absent, refusing entity
#   expansion on the researcher-supplied XML (same precedent and version as
#   paper2talk/scripts/requirements.txt). Pinned here so a plain
#   `pip install -r requirements.txt` actually installs the hardened parser
#   instead of silently degrading to the fallback.
