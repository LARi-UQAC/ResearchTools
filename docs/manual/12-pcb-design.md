# PCB design, mixed signals

Chapter 12 of the ResearchTools manual. Back to [table of contents](../../README.md).

**This chapter is a placeholder.** It is empty on purpose and will be written during the week of
2026-10-26, together with the Vibe Design book project (see [chapter 00](00-purpose.md)).

## What it will cover

A printed-circuit-board design, mixed-signal boards included, treated as generated work that is often
code, in the same way the neighbouring chapters treat software: written in dialogue with coding
agents, reviewed in a bounded loop, and checked before anything is fabricated. The content is not
decided yet, so nothing below is a feature of this repository today.

## What exists today

No skill, agent or command in this repository handles PCB design. The code loop and the choice of
executor in [chapter 11](11-local-coding.md), the nightly pipeline in
[chapter 14](14-aider-pipeline.md) and the [dashboard](10-rt-observe-dashboard.md) apply to any
project, including one that holds hardware sources, but they know nothing about boards.
